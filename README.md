# 💻 Laboratorios INSUCO Valparaíso

**Sitio web informativo sobre los laboratorios de computación del Instituto Superior de Comercio de Valparaíso (INSUCO).**

## 📌 Descripción del proyecto

Este proyecto consiste en el desarrollo de un sitio web diseñado para facilitar el acceso a información sobre los laboratorios de computación del Liceo INSUCO de Valparaíso. Su propósito es ofrecer una plataforma sencilla, organizada y accesible, donde los estudiantes y usuarios puedan consultar las características y la disponibilidad de cada laboratorio.

El sitio fue desarrollado utilizando **HTML y CSS**, aplicando conocimientos de diseño web, organización de archivos, navegación entre páginas y adaptación a distintos tamaños de pantalla.

## 🎯 Objetivo

Crear una plataforma informativa que permita conocer los cinco laboratorios de computación del establecimiento, facilitando la consulta de sus características, ubicación y horarios de funcionamiento.

## ✨ Características principales

* 🖥️ **Cinco laboratorios:** páginas individuales con información específica de cada uno.
* 📍 **Ubicación:** información sobre dónde se encuentra cada laboratorio dentro del establecimiento.
* 💻 **Equipamiento:** cantidad de computadores disponibles.
* ⚙️ **Sistema operativo:** información del sistema utilizado en cada laboratorio.
* 🕒 **Horarios:** horario de funcionamiento de 08:00 a 16:05 horas.
* 🔄 **Disponibilidad:** información sobre el estado del laboratorio, ocupado o disponible.
* 🧭 **Navegación sencilla:** menú con accesos a Inicio, Laboratorios, Sobre mí y Contacto.
* 📱 **Diseño adaptable:** reglas CSS para mejorar la visualización en celulares y tablets.
* 🎨 **Diseño visual:** tarjetas informativas, botones, bordes redondeados, sombras y efectos al pasar el cursor.
* ✉️ **Formulario de contacto:** sección para facilitar la comunicación con los responsables del proyecto.

## 🏫 Información de los laboratorios

El sitio incluye información de los laboratorios 1 al 5. Como referencia general, se considera que cada laboratorio cuenta con 30 computadores y funciona entre las 08:00 y las 16:05 horas.

La ubicación y el sistema operativo pueden variar según el laboratorio. La disponibilidad debe consultarse de acuerdo con la información publicada en el sitio.

## 🛠️ Tecnologías utilizadas

* **HTML5:** estructura y organización del contenido de las páginas.
* **CSS3:** diseño visual, colores, tarjetas, efectos y adaptación a distintos dispositivos.
* **Git y GitHub:** organización, almacenamiento y publicación del proyecto.
* **Diseño responsive:** adaptación de la interfaz a diferentes tamaños de pantalla.

## 🚀 Cómo utilizar el proyecto

1. Clona o descarga este repositorio.
2. Abre la carpeta del proyecto en tu computador.
3. Ejecuta el archivo `index(2).html` en un navegador web.
4. Utiliza el menú de navegación para acceder a los laboratorios y las demás secciones.

No se requiere instalar dependencias adicionales para visualizar las páginas HTML y CSS.
