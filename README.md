# Laboratorios INSUCO Valparaíso #

Descripción:

Este proyecto consiste en un sitio web informativo sobre los laboratorios de computación del Liceo INSUCO de Valparaíso. Su objetivo es facilitar el acceso a información como la ubicación de cada laboratorio, cantidad de computadores, sistema operativo, horario y estado de disponibilidad.

El sitio está desarrollado principalmente con HTML y CSS, buscando una estructura clara, sencilla y fácil de navegar.

Contenido del sitio:

La página principal presenta el proyecto y permite acceder a los diferentes laboratorios. Desde allí se puede consultar información específica de los laboratorios 1 al 5.

Cada laboratorio muestra:

1)Ubicación dentro del establecimiento.

2)Cantidad de computadores.

3)Sistema operativo.

4)Horario de funcionamiento.

5)Estado del laboratorio: ocupado o disponible.

Según la información incorporada en las páginas, los laboratorios cuentan con 30 computadores y tienen un horario de 8:00 AM a 16:05 PM. La información de ubicación y sistema operativo puede variar según cada laboratorio.

Estructura del proyecto:

1)index(2).html: página de inicio y presentación general del sitio.

2)laboratorios(1).html: listado general de los cinco laboratorios.

3)laboratorio1(2).html a laboratorio5(2).html: páginas individuales con información de cada laboratorio.

4)contacto2(2).html: formulario de contacto.

5)Archivos style3.css, style4.css, style5.css, style6.css, style7.css y style8.css: hojas de estilo utilizadas en las distintas páginas.

6)Imágenes de los laboratorios: utilizadas para complementar visualmente la información.

Diseño:

El sitio utiliza tarjetas, menús de navegación, botones y secciones informativas para organizar el contenido. Los estilos incorporan colores, bordes redondeados, sombras y efectos al pasar el cursor.

También se incluyen reglas @media en algunas hojas de estilo para adaptar la visualización a pantallas más pequeñas, como tablets y celulares.

Objetivo del proyecto

El proyecto busca crear una página funcional y fácil de entender para conocer y ubicar los laboratorios de computación del INSUCO de Valparaíso.

Además, permite aplicar conocimientos de:

1)HTML para la estructura del sitio.

2)CSS para el diseño y la presentación.

3)Enlaces entre páginas para la navegación.

4)Diseño adaptable para distintos tamaños de pantalla.

5)Organización de archivos e imágenes para publicar el proyecto en GitHub.

Navegación:

El sitio cuenta con accesos a:

1)Inicio

2)Laboratorios

3)Sobre mí

4)Contacto

5)Desde las páginas individuales también se puede regresar al inicio.
